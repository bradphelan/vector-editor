Simple Vector Editor
====================

A simple vector editor that immediately generates C++ code representing the points that are drawn.

**Now powered by Paper.js!** This application has been upgraded to use Paper.js for improved vector graphics rendering and manipulation.

https://bradphelan.github.io/vector-editor/

![image](https://github.com/bradphelan/vector-editor/assets/17650/7d4bf79d-c255-4919-bdd8-0f59c8815062)

## Features

- **Freehand drawing**: Draw smooth curves with your mouse
- **Line drawing**: Create precise line segments 
- **Edit mode**: Edit existing curves by dragging points
- **Smoothing**: Apply Douglas-Peucker algorithm to smooth curves
- **Export**: Generate C++ code for your drawings
- **Paper.js integration**: Enhanced vector graphics capabilities

## Technologies Used

- **Svelte**: Frontend framework
- **TypeScript**: Type-safe development
- **Paper.js**: Vector graphics library
- **Vite**: Build tool and development server
